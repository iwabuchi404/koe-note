### **フェーズ4: バンドルサイズ最適化** 📦効果重視
**目標**: 467KBのバンドルサイズを300KB以内に削減

#### 4.1 現在の問題
- **webpack警告**: バンドルサイズが244KB制限を超過
- **orphan modules**: 390KBの未使用モジュール存在
- **重複依存**: 複数の類似ライブラリ読み込み

#### 4.2 最適化戦略
1. **Tree Shaking強化**: 未使用コードの除去
2. **コード分割**: ルート別遅延読み込み
3. **依存関係最適化**: 重複ライブラリの統合

#### 4.3 実行ステップ
```javascript
// webpack.config.js 最適化
const config = {
  // Tree Shaking強化
  optimization: {
    usedExports: true,
    innerGraph: true,
    splitChunks: {
      chunks: 'all',
      cacheGroups: {
        vendor: {
          test: /[\\/]node_modules[\\/]/,
          name: 'vendors',
          chunks: 'all',
        },
      },
    },
  },

  // コード分割
  entry: {
    main: './src/renderer/index.tsx',
    audio: './src/renderer/audio/index.ts', // 遅延読み込み対象
  },
};
```

**リスク評価**:
- **低リスク**: webpack設定変更のみ
- **効果確認**: ビルド前後のサイズ比較
